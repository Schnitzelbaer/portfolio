I design digital products for banks, public transport and healthcare, which are fields where the subject matter is complicated and the people using the product have little patience for it. My work starts with understanding the system behind a problem and ends with an interface that hides most of that system again.

I like working close to engineering. I prototype in code when it helps a decision, write specs that developers want to read, and care about accessibility because it makes products better for everyone.

Before design, I studied communication science, which still shapes how I run research and how I write interface copy. Outside work you will find me on a bike somewhere in the Alps.
